# Segnalare una vulnerabilità

Se trovi un problema di sicurezza nella piattaforma, **non aprire una issue pubblica**.
Scrivi a **new@albertina.academy** con:

- una descrizione del problema e di come riprodurlo;
- le pagine o le parti del codice coinvolte;
- il tuo contatto, se vuoi essere ricontattato o citato.

Rispondiamo entro 7 giorni e ti teniamo aggiornato fino alla correzione.
